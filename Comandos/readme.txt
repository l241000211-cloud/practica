ls — Muestra una lista rápida con los nombres de archivos y carpetas del directorio actual.

ls -l — Muestra el contenido en formato largo con permisos, dueño, tamaño en bytes y fecha de modificación.

ls -la — Lista todo en formato largo incluyendo archivos y carpetas ocultos (los que inician con un punto).

ls -lh — Lista en formato largo mostrando los tamaños de archivo de forma legible para humanos (KB, MB, GB).

cd <carpeta> — Cambia de directorio y entra a la carpeta especificada (ejemplo: cd Descargas).

cd .. — Sube un nivel en la estructura de carpetas (regresa a la carpeta anterior).

cd ~ — Regresa de inmediato al directorio personal del usuario (/home/usuario).
